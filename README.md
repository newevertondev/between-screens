# Between Screens

Projeto desenvolvido por Neweverton Fernandes da Silva com o objetivo de promover conscientização sobre segurança digital entre jovens.

## Sobre o Projeto

Between Screens é uma plataforma educativa criada para alertar sobre riscos presentes no ambiente digital, como:

- Manipulação online
- Comunidades perigosas
- Ameaças e chantagens
- Perfis falsos
- Deepfakes
- Golpes digitais

O projeto busca incentivar a prevenção, o pensamento crítico e a procura por ajuda em situações de risco.

## Funcionalidades

- Caso real adaptado para fins educativos
- Sinais de alerta
- Questionário de conscientização
- Orientações de segurança digital
- Canais de apoio
- Conteúdo sobre Inteligência Artificial e Deepfakes
- Participação de profissionais convidados

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
